## Tools used
- [GitHub.com](https://github.com/) hosting this project and allowing me to write the code over `Codespaces`
- [chatGPT.com](https://chatgpt.com/) used to generate all the icons of this page
- [Qwer.ai](https://chat.qwen.ai/) One of the best free AI to generate code. Used for:  
    - icon library to convert png to ico  
    - xml viewer  
    - header info editor  
    - formula editor
- [Showdown (Github)](https://github.com/showdownjs/showdown) converts MD-files to HTML (this help)
- [UPNG (Github)](https://github.com/photopea/UPNG.js/) to reduce the spritesheet image size
- [Pako (Github)](https://github.com/nodeca/pako) for UPNG and for creating zips
- [LameJS (NPM)](https://www.npmjs.com/package/lamejs) to compress MP3 files (not used yet)
