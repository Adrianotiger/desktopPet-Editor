# Information

DesktopPet Editor is a lightweight browser-based tool to create and edit XML animations for DesktopPet characters.

It helps you open, modify, and save pet projects with a visual interface instead of editing raw XML manually. The editor is focused on making desktop animations easier to manage, customize, and reuse.

## What it does

- edit animation data and project files
- manage sprite and image references
- configure header, spawn, and behavior settings
- use a formula editor for custom logic
- save and reuse XML-based pet definitions

## Why it exists

DesktopPet animations are reusable and open by design, so a good editor makes it easier for developers, creators, and hobbyists to build and adjust their own pets without dealing with the XML structure by hand.

## Main sections

- Animation editor
- Header editor
- Image / spritesheet editor
- Spawn editor
- Formula editor
- XML viewer

## Requirements

This project is designed for modern browsers with current web standards and file access support.
